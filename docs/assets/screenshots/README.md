# Documentation screenshots

These seven PNGs show YATA **0.96.2 (build 31)** running on a connected Pixel in **demo mode**,
captured on **27 October 2026**. Names, tasks, assignments and statistics are sample data.
The theme, font and layout reflect that device's configuration, not a required default.

The documentation copies reuse the existing Play Store captures from
`artifacts/play-store/2026-10-27/phone/`. Each is an unchanged 1080 × 1920, 24-bit RGB PNG.
No new device capture or app-data modification was needed for this documentation update.
These copies live with the guides so published documentation does not depend on a local
artifact directory or externally hosted image attachments.

| File | Screen | Used to explain |
| --- | --- | --- |
| `01-today.png` | Today | Daily planning, filters, overdue work and estimates |
| `02-project-groups.png` | Projects | Groups, stars, progress and archived projects |
| `03-people.png` | People | Ownership, delegation and workload |
| `04-tags.png` | Tags | Grouped labels, descriptions and open counts |
| `05-upcoming.png` | Upcoming calendar | Month planning and day agenda |
| `06-task-details.png` | Task details | Estimates, tracked time, sections and nested subtasks |
| `07-analytics.png` | Analytics | Task health, effort and activity |

record the new version/date and use sample data with authorized device access.
